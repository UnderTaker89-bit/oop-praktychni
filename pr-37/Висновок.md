# Практична 37 Узагальнені класи

Обмеження where T : Model гарантує доступ до Id без приведення типів. Статичний список зберігає дані в пам’яті процесу й є спільним для всіх екземплярів одного закритого типу репозиторію. Для GenericRepository<Posting> та GenericRepository<ContactPerson> створюються різні статичні поля, тому їхні дані й лічильники ідентифікаторів незалежні. Після завершення процесу ці списки зникають. GetAll повертає копію списку, але самі сутності залишаються посилальними об’єктами. Синхронізація захищає операції репозиторію; пряме редагування сутності поза репозиторієм не є окремою транзакцією.
