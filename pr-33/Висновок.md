# Практична 33 Узагальнені методи

IndexOf порівнює елементи через EqualityComparer<T>.Default, тому обмеження не потрібне. Reverse змінює лише позиції елементів і також не потребує обмеження. Min і Max потребують порядку: where T : IComparable<T> гарантує можливість порівняння. Comparer<T>.Default обробляє порівняння, зокрема null для посилальних типів. Для порожнього масиву IndexOf повертає -1, Reverse нічого не робить, а Min і Max повідомляють про відсутність елементів. LINQ не використано.
